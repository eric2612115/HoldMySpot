# Prior art

The nearest existing services and PayPal AI Hackathon entries, what each does, what its public page or README does not describe, and where this repository tests the difference. Each row says when its source was read: a hackathon repository's README at the commit read (the link opens that version), and a web page on the date read, with an archived copy where one exists. "Does not describe" means we found no sign of it in that version of the page; it is not a claim about what the product could do. A correction changes a row: open an issue with the link.

Every part of HoldMySpot exists somewhere: paid line-sitting, bids as payment holds, falling prices, reverse auctions and bids on fees, photo proof of a task. What we did not find is the combination built here, stated as a falsifiable sentence at the end.

## What PayPal's own documentation and sandbox say

- PayPal's guide [Authorize a payment and capture funds later](https://developer.paypal.com/docs/checkout/standard/customize/authorization/) (read 2026-11-08) says an authorization holds the funds for 29 days, that the payment should be captured within a 3-day honor period, and that it can be reauthorized after the honor period within those 29 days. HoldMySpot reauthorizes untouched holds from day 4 (`server/test/money.test.ts`); on the sandbox this waits for 2026-11-10 (gate G10, `docs/SANDBOX-GATES.md`).
- PayPal's sandbox accepted captures up to exactly 115% of an authorization and refused 115.1% with `MAX_CAPTURE_AMOUNT_EXCEEDED` (`docs/SANDBOX-GATES.md`, edge cases; `server/test/paypal/sandbox-parity.test.ts`). HoldMySpot's own limit is 100% (P2; `server/test/money.test.ts`), so the headroom is never used.
- PayPal's Payouts API reference (read 2026-11-08) offers a cancel only for an unclaimed payout item ([Cancel unclaimed payout item](https://developer.paypal.com/docs/api/payments.payouts-batch/v1/)); HoldMySpot sends the shop price and shipping only after the final capture.
- Paid line-sitting is an existing service in the US: the Fortune article and TaskRabbit's service page above.

## "Firsts", written so they can be proven wrong

1. **The combination built here.** We found no product, app or hackathon entry that does all four of these: (a) prices only the queuer's time, with the item paid at the receipt's price, up to the requester's cap; (b) lets that fee fall only after a passed check-in at the shop (the position the phone reports inside the geofence, and an AI-read line photo with a one-time code); (c) captures from a PayPal authorization only after an AI-read receipt passes rule checks or a person approves it; (d) keeps every match inside that authorization. **It is false if** a public repository, product page or hackathon entry published before the hackathon's deadline, 2026-11-12, does all four. Each part is tested here: (a) P1, `shared/src/money.test.ts` and attack row 1; (b) P6, the server days in `server/test/engine.property.test.ts` and attack rows 9 and 10; (c) P3 (the server days check that every capture belongs to a job whose receipt passed or was approved), `docs/ABLATION.md` and attack rows 2 to 7; (d) P7 in shared, server and ops, P2 and attack row 8. The limits of (b) and (c), a faked position and a receipt that agrees with itself, are README's Known limits and attack rows 21 and 22.
2. **No other PayPal AI Hackathon entry for paid line-sitting in the searches we kept.** On 2026-11-08, nine GitHub code searches for "PayPal AI Hackathon" together with line sitting, a line sitter, waiting or standing in line, "in line for you", a queue sitter, a queuer or "hold my spot" found no file in any public repository, and ten repository searches found no line-sitting entry ([docs/evidence/prior-art-search-20261108.json](docs/evidence/prior-art-search-20261108.json): every query, its total and every repository it returned; a broader code search for "paypalaihackathon" and "queue" returned 69 repositories, listed there by name and not each read). `node scripts/prior-art-search.mjs --out <file>` runs the same list again; it will be run again on 2026-11-12. **It is false if** a public entry for paid line-sitting was published before the deadline.
